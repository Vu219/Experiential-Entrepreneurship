## 2. Logic Chain

1. **Initial Content Generation (`ContentItemMapper.toGeneratedVersion`)**:
   During initial generation, `ContentVersion` instances are created with `voiceAligned`, `voiceScore`, `voiceNotes`, and `imagePrompt` populated directly from AI generation results (`GeneratedContentResult.brandVoiceCheck` and `GeneratedContentResult.imagePrompt`).
2. **Platform Formatting Flow (`ContentFormattingWorkerServiceImpl.savePlatformResult`)**:
   When users run platform formatting, the background worker invokes the AI formatter for each platform and receives `FormatResultPayload` (containing `ContentVersionPayload` objects). `ContentVersionPayload` does not include brand voice evaluations or image prompts because formatting focuses solely on platform-tailored caption, hashtags, media format, and CTA.
3. **Information Loss Root Cause**:
   In `ContentFormattingWorkerServiceImpl.savePlatformResult`, line 254 creates new `ContentVersion` entities via `contentFormattingMapper.toContentVersion(payload)`. Lines 257–260 only restore `script` and `mediaPrompt` from `source`. Brand voice (`voiceAligned`, `voiceScore`, `voiceNotes`) and `imagePrompt` are omitted, resetting to `null` in the formatted versions.
4. **Surgical Solution**:
   In `ContentFormattingWorkerServiceImpl.savePlatformResult`, expand the `if (source != null)` block to copy:
   - `version.setImagePrompt(source.getImagePrompt());`
   - `version.setVoiceAligned(source.getVoiceAligned());`
   - `version.setVoiceScore(source.getVoiceScore());`
   - `version.setVoiceNotes(source.getVoiceNotes());`
5. **Test Fixtures & Verification Strategy**:
   - Enhance `fixture()` in `ContentFormattingLateResultTest` with representative brand voice metrics (`voiceAligned = true`, `voiceScore = 92`, `voiceNotes = "Giọng văn tự tin, chuyên nghiệp"`) and `imagePrompt = "Ảnh vuông bàn trang điểm tối giản, tông pastel."`.
   - Update `replacementVersionTakesOverAScheduleCreatedDuringFormatting()` to assert inheritance on schedule takeover.
   - Add a dedicated test `formattedVersionInheritsBrandVoiceAndImagePromptFromSource()` to verify complete inheritance independently.

## 3. Caveats

1. **Source Nullability**:
   If `sourceVersionId` does not resolve to an existing `ContentVersion` entity (`source == null`), the worker safely bypasses copying via the null-check without throwing exceptions.
2. **Multi-round Formatting / Re-formatting**:
   In `ContentFormattingWorkerServiceImpl.markRunningAndBuildContext` (lines 191-193):
   `UUID sourceId = active.getSourceVersionId() != null ? active.getSourceVersionId() : active.getId();`
   When re-formatting an already formatted version, the system resolves back to the root `sourceId`, ensuring the original brand voice check and image prompt are never corrupted or lost across successive formatting iterations.
3. **No Unrequested Changes**:
   No changes to `ContentVersionPayload`, `ContentFormattingMapper`, or database schema are required or proposed. The change is isolated to `ContentFormattingWorkerServiceImpl` and verified by `ContentFormattingLateResultTest`.
